Un ús actual: text que envolta una imatge

Una imatge flotant deixa que el text flueixi al seu costat i continuï a sota quan supera la seva alçada. Aquest comportament és útil en una composició editorial. A diferència de les targetes en una graella, aquí volem que les línies de text envoltin la imatge.

.float-article { display: flow-root; }
.float-article img { float: left; margin: 0 1rem 1rem 0; }

flow-root crea un context de format que conté la imatge flotant. Amb molt poc text, el pare continua incloent l’alçada de la imatge.

Context històric: un menú amb float

Abans de Flexbox s’utilitzava float per a menús. Conservem aquest exemple per entendre codi antic; per construir una navegació nova practica Flexbox.

  • Inici
  • Flexbox
  • Grid
.float-menu > li { float: left; }
.float-menu::after { content: ""; display: block; clear: both; }

El pseudo-element amb clear fa que el pare recuperi l’alçada dels fills flotants. Canviar left per right també altera la disposició visual: compara-la amb l’ordre de tabulació.

Practica i comprova

Substitueix el menú flotant per Flexbox. Quines regles pots eliminar?

Mostra una solució explicada 
.float-menu { display: flex; flex-wrap: wrap; gap: 1rem; }
.float-menu > li { float: none; margin: 0; }
.float-menu::after { content: none; }

Flexbox manté els fills en el seu layout; ja no necessites clear ni el pseudo-element. Els selectors continuen limitats a aquest menú.
