Grid: línies amb nom

Objectiu: Expressa el mateix disseny amb noms significatius.

Edita assets/css/style.css i aquest HTML. Canvia una propietat cada vegada, prediu el resultat i comprova’l al navegador.

Mateix resultat, noms amb significat

Informació extra
Peu
.containergrid2 {
  display: grid;
  grid-template-columns: [inici] 1fr [principal] 2fr [lateral] 1fr [final];
  gap: 1rem;
}
.headergrid2 { grid-area: 1 / inici / 2 / final; }
.sidebargrid2 { grid-area: 2 / inici / 3 / principal; }
.contentgrid2 { grid-area: 2 / principal / 3 / lateral; }
.sidebargrid22 { grid-area: 2 / lateral / 3 / final; }
.footergrid2 { grid-area: 3 / inici / 4 / final; }

L’ordre de grid-area amb quatre valors és: fila inicial / columna inicial / fila final / columna final. Els noms entre claudàtors identifiquen línies, no àrees.

Practica i comprova

Fes que el peu ocupi només les columnes central i dreta, mantenint-lo a la tercera fila.

Mostra una solució explicada 
.footergrid2 { grid-area: 3 / principal / 4 / final; }

La línia principal és l’inici de la segona columna. La primera columna de la tercera fila queda buida.
