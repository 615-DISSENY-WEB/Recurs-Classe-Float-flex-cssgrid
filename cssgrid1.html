Grid: posicionament per línies

Objectiu: Llegeix les línies i ocupa diverses cel·les.

Edita assets/css/style.css i aquest HTML. Canvia una propietat cada vegada, prediu el resultat i comprova’l al navegador.

Col·loca cada regió entre línies

Peu
.containergrid1 {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 1rem;
}
.headergrid { grid-column: 1 / 4; grid-row: 1 / 2; }
.sidebargrid { grid-column: 1 / 2; grid-row: 2 / 3; }
.contentgrid { grid-column: 2 / 3; grid-row: 2 / 3; }
.sidebargrid12 { grid-column: 3 / 4; grid-row: 2 / 3; }
.footergrid { grid-column: 1 / 4; grid-row: 3 / 4; }

El final és una línia, no una columna inclosa: 1 / 4 ocupa tres columnes. Aquest esquema és un laboratori de posicionament; a la lliçó d’àrees el farem adaptable.

Practica i comprova

Reescriu la capçalera perquè comenci a la línia 1 i ocupi tres columnes amb span.

Mostra una solució explicada 
.headergrid { grid-column: 1 / span 3; }

span indica quantes pistes ocupa l’element, en lloc de donar el número de la línia final.
