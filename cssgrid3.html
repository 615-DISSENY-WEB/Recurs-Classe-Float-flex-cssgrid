Grid: àrees i disseny adaptable

Objectiu: Passa d’una columna a una estructura de tres columnes.

Edita assets/css/style.css i aquest HTML. Canvia una propietat cada vegada, prediu el resultat i comprova’l al navegador.

Dibuixa la pàgina amb noms

Fem tres passos: activem Grid al pare, dibuixem les zones amb noms i indiquem quin fill va a cada zona.

  1. display: grid activa la graella.
  2. grid-template-areas dibuixa les files: cada text entre cometes és una fila.
  3. grid-area: cap col·loca la capçalera a la zona que hem anomenat cap.

Menú
Contingut principal
Informació extra

.containergrid3 {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-areas:
    "cap cap cap"
    "menu contingut extra"
    "peu peu peu";
  gap: 1rem;
}
.headergrid3 { grid-area: cap; }
.sidebargrid3 { grid-area: menu; }
.contentgrid3 { grid-area: contingut; }
.sidebargrid32 { grid-area: extra; }
.footergrid3 { grid-area: peu; }

1fr 2fr 1fr reparteix l’espai en tres columnes: la central té dues parts i les altres una cadascuna.

El dibuix té tres files: la capçalera ocupa tota l’amplada a dalt, el cos es reparteix en tres columnes (menú, contingut, extra) i el peu torna a ocupar tota l’amplada a baix. Així es defineix el disseny de la pàgina sense dependre de l’amplada de la finestra.

Les àrees amb nom han de formar rectangles. Cada fila del dibuix ha de tenir el mateix nombre de cel·les. El punt . representa una cel·la buida.

El canvi de disposició no canvia l’ordre de lectura ni de tabulació de l’HTML. Escriu primer un ordre lògic i conserva’l en totes les amplades.

Practica i comprova

Situa la informació extra en una fila pròpia a tota l’amplada, abans del peu.

Mostra una solució explicada 
.containergrid3 {
  grid-template-columns: 1fr 2fr;
  grid-template-areas: "cap cap" "menu contingut" "extra extra" "peu peu";
}

El nou dibuix té dues columnes i quatre files. No cal tocar les assignacions grid-area dels fills ni l’HTML.
