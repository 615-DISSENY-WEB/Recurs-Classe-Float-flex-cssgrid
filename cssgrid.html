.containergrid {

fr reparteix espai disponible; el contingut mínim també pot condicionar les mides. La columna central rep dues fraccions. Les dues primeres files són explícites; la tercera es crea automàticament perquè hi ha vuit fills.

Activa la superposició Grid a l’inspector: tres columnes tenen quatre línies de delimitació.

Practica i comprova

Fes tres columnes iguals amb repeat(). Afegeix dos fills: quantes files tindràs?

Mostra una solució explicada 
.containergrid { grid-template-columns: repeat(3, 1fr); }

Amb deu fills es creen quatre files. Les dues últimes es creen automàticament.
